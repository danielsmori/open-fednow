# Adjacent resources and evaluation boundary

Reviewed October 1, 2026 against linked first-party documentation. This is a public-description comparison, not a hands-on benchmark. “Unknown” means we did not verify it; silence on a webpage is not evidence that a feature is absent. Access and prices may change.

| Resource | Source and documented setup | Payment-specific rules and inspectable effects | External-target contract and access |
|---|---|---|---|
| [Federal Reserve FedNow resources](https://www.frbservices.org/resources/financial-services/fednow-service-resources/) and [DevRel](https://www.frbservices.org/resources/financial-services/fednow-service-resources/fednow-devrel/) | Official operating material is public; technical resources require FedLine credentials. Customer-test setup is governed by those resources. | Authoritative FedNow operating and technical specifications; not tested with this package. | Credentialed participant/provider access; compatibility with this package's driver is unknown. |
| [Payapt FedNow Simulator](https://payapt.com/simulator) | Cloud subscription simulator; source availability and detailed setup were not verified. | Payapt describes FedNow-shaped messaging and product validation. Exact fault invariants and internal financial-effect visibility were not tested. | An equivalent external driver, terms and actual price are unknown. |
| [Mojaloop Testing Toolkit](https://docs.mojaloop.io/technical/technical/ml-testing-toolkit/) ([source](https://github.com/mojaloop/ml-testing-toolkit)) | Public source with documented CLI/UI and Docker quick start. | Mojaloop DFSP/Hub integration tests and assertions; not tested for these specific FedNow-shaped HOLD/POST/RELEASE observations. | Documented peer endpoint and self-testing; mapping to this seven-operation driver was not attempted. |
| [Toxiproxy](https://github.com/Shopify/toxiproxy) and [Testcontainers Toxiproxy module](https://java.testcontainers.org/modules/toxiproxy/) | Public source and installation examples for network fault injection and disposable dependencies. | General network faults; payment state/effect assertions must be supplied by the application test. | Can sit between processes; no payment-specific target driver is claimed. |
| [FIS Money Movement Hub](https://www.fisglobal.com/products/money-movement-hub) | FIS describes a hosted single-API gateway for FedNow, RTP, ACH and other schemes; source, detailed setup and actual price were not verified. | Production-oriented payment connectivity is advertised; the specific local-effect oracle here was not tested. | Public page describes a single API, but mapping to this evaluation driver and access terms are unknown. |

OpenFedNow's measured contribution is an inspectable synthetic scenario register, independent remote-effect trace and a driver contract reused across its Java configurations and an author-built Python target. It is not a unique simulator, live rail integration, bank adoption or commercial superiority claim. See [the evaluator guide](evaluator-guide.md) for exact local setup and limits.
